# Security Policy

## Supported release

The current specification line is **ACIE v1.0**. Security reports affecting implementations should identify the exact repository, commit, component, and deployment context.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Use GitHub's **Report a vulnerability** action in the repository's Security tab when private vulnerability reporting is available. If that option is unavailable, contact the repository owner through the verified contact method listed on the GitHub profile and request a private disclosure channel.

Include a concise description, impact, affected versions/commits, reproduction steps, and any proposed mitigation. Do not include live credentials, personal data, or destructive proof-of-concept payloads.

## Handling

Reports will be triaged in good faith. Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. No response-time guarantee is made by this policy.

## Scope

This policy covers this repository's specification, schemas, validation code, build tooling, and published artifacts. Deployments built from the specification may have separate security contacts and responsibilities.
